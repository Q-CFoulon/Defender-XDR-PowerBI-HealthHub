# Dashboard Screenshots

This directory contains screenshots of the Power BI dashboards powered by the Defender XDR Health Hub.

## Adding Screenshots

To contribute screenshots:

1. Build and connect the Power BI report to a live or sample data environment using `powerbi/power-query-sample.m`.
2. Capture each dashboard page as a PNG image at 1920×1080 resolution or higher.
3. Save files using the naming convention below and open a pull request.

| File name | Dashboard |
|---|---|
| `dashboard-overview.png` | Executive Overview (Secure Score + Exposure Score summary) |
| `dashboard-program-initiatives.png` | Program Initiatives |
| `dashboard-top-initiatives.png` | Top Initiatives |
| `dashboard-secure-scores.png` | Secure Scores (M365 & Cloud) |
| `dashboard-vulnerability-overview.png` | Vulnerability Overview |
| `dashboard-remediation-recommendations.png` | Remediation Recommendations |
